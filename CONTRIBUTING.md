# Contributing to SuperChatGPT

We love your input! We want to make contributing to SuperChatGPT as easy and transparent as possible.

## How to Contribute

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/amazing-feature`)
3. Commit your changes (`git commit -m 'Add amazing feature'`)
4. Push to the branch (`git push origin feature/amazing-feature`)
5. Open a Pull Request

## Development Setup

See README.md for platform-specific setup instructions.

## Code Style

- TypeScript: Follow ESLint configuration
- Python: PEP 8
- Rust: rustfmt
- C#: Microsoft C# style guide

## Testing

Please write tests for new features and ensure all tests pass.

## Reporting Issues

Use GitHub Issues to report bugs or suggest features.
